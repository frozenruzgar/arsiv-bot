# Arşiv Botu İndirme

Instagram Reels videolarını seçtiğiniz yerel klasöre MP4 olarak indiren Windows uygulaması.

## İndir

Depodaki **`Arsiv-Botu-Windows.zip`** dosyasını indirip bilgisayarınızda bir klasöre çıkarın.

1. `Kurulum.bat` dosyasını çalıştırın.
2. Kurulum tamamlanınca `Baslat.bat` dosyasını açın.
3. Panel `http://127.0.0.1:5090` adresinde açılır.

### Gereksinimler

- Windows 10/11
- Google Chrome
- Python 3

Hesap çerezleri, profil bilgileri ve indirilen videolar yalnızca kullanıcının bilgisayarında tutulur; indirilebilir pakette kişisel veri bulunmaz.
